# Repository operating rules

- Never commit or publish `.env` or credential values.
- Google Ads tooling is read-only and is limited to keyword-planning historical metrics.
- Do not create or modify Google Ads campaigns.
- Do not run Supabase queries or mutate production systems.
- Companies House is registry evidence; it does not prove trading quality or buying intent.
- Preserve raw-source lineage and distinguish observed facts, derived calculations, inference and unknowns.
- Keep large snapshots and raw captures in `private-data/`; GitHub Pages may publish only generated files under `docs/`.
- Do not push unless the user explicitly requests publication.
- Do not add co-authors to commits.
